# Alderpoint DNS V2 Feature Matrix

The previous V2 feature/parity matrix is retired with the frozen private V2 implementation.

A clean V2 reboot is now under private development. Current V2 requirements, feature sequencing, implementation state, internal comparisons, and release-gate evidence are intentionally not published here while development is active.

Alderpoint DNS **v1.1.1 remains the current public stable release**. Public V1 behavior and documentation remain the source of truth for the released product.

The retired matrix may still be retained privately as a requirements catalog and source of test ideas, but its old implementation statuses must not be treated as current V2 progress.

No public V2 package, release candidate, tag, or release exists unless explicitly announced in the future.
