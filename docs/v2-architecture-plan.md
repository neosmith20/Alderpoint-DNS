# Alderpoint DNS V2 Architecture

This document described the previous private V2 implementation and is no longer the active architecture plan.

That implementation is frozen and preserved for historical engineering reference only. A clean V2 reboot is now being developed privately, and its current architecture, roadmap, implementation checkpoints, and internal design documents are intentionally not published here during active development.

Alderpoint DNS **v1.1.1 remains the current public stable release**. Nothing in this file changes the supported V1 release line, public V1 history, tags, packages, or release artifacts.

The previous V2 may still be consulted privately for proven behavior, tests, benchmarks, failure lessons, migration knowledge, and other reusable evidence, but its runtime topology, storage layout, development model, and UI structure are not automatically carried forward.

No public V2 release or release candidate exists unless explicitly announced in the future.
