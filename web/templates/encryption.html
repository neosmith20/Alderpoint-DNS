Protocols

Wildcard listen addresses such as 0.0.0.0 and :: expose client DNS listeners on every host interface allowed by dnsdist ACLs and firewall policy. Use loopback or a specific LAN address for private testing.

{% if not capabilities.doq or not capabilities.doh3 %}

DoQ/DoH3 need a dnsdist build with QUIC support, which Debian's own default dnsdist package does not include. Installing dnsdist from the official PowerDNS repository (see docs/dnsdist.md) adds this support; Alderpoint DNS detects it automatically and enables these controls once it's present.

{% endif %}
DNSCrypt (experimental){% if not capabilities.dnscrypt %} {{ ui.status_badge("Unsupported by installed dnsdist", "neutral") }}{% endif %}

DNSCrypt requires generating provider/resolver key material through dnsdist's own console interface. This is not reliably available on every install; if generation fails, DNSCrypt is automatically left disabled and the deployment message explains why, without blocking DoH/DoH3/DoT/DoQ.
