Private keys and credentials (off by default)

Including private keys bundles TLS private keys, the DNSCrypt provider/resolver private keys, the web session-signing secret, and dnsdist API/webserver credentials into the archive. Anyone who obtains this archive (and its password, if set) can impersonate this server or the admin UI. Only enable this for a full disaster-recovery backup stored somewhere trusted.

Scheduled Backups

Scheduled backups use the same component defaults as a manual backup with no password (unencrypted), and are pruned to the retention count after each run.

Restore Upload Limits

Governs native Alderpoint backup uploads/restores only (separate from the 10 MiB spreadsheet/text import limit). The extracted-size ceiling protects against a compressed archive bomb regardless of the uploaded file's size.

Notes

The SQLite database is always captured through SQLite's own online backup API, never a raw file copy, so a concurrently-writing web app or analytics collector can never produce a torn archive. Restores always take a fresh safety backup of the current state first and automatically roll back if any post-restore health check fails.
