Cache Tuning

This VM has {{ total_memory_mb }}MB of RAM; the default cache size is chosen conservatively so BIND never crowds out dnsdist, the web app, and analytics. Positive/negative TTL bounds default to BIND's own built-in defaults — they are not aggressively overridden. Recursive clients limits simultaneous recursive lookups accepted by BIND; lowering it too far can reject bursts of normal client traffic.

Prefetch and serve-stale

Serve-stale answers an expired cached record immediately (bounded by max stale TTL) while BIND refreshes it in the background, if the authoritative source is unreachable. Disabled by default.
