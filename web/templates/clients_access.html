About ClientIDs

A ClientID is a strong random identifier (192-bit / 48 hex minimum, 256-bit / 64 hex recommended), generated with a cryptographically secure source and never accepted below the 192-bit minimum -- Alderpoint does not support 128-bit/32-hex or other short/weak ClientIDs. It identifies a client on encrypted-DNS transports (DoT/DoQ via TLS SNI, DoH via the request path); this dnsdist build (2.1.1) supports SNI-based matching for DoT/DoQ and path-based matching for DoH. A ClientID is identification, not authentication: its length makes it extremely hard to guess, but anyone who learns the exact value can present it too -- there is no certificate or signature involved. A 256-bit ClientID does not fit a single DNS hostname label (63 characters), so DoT/DoQ transports use a lossless Base32-encoded label instead of the raw hex; DoH's path has no such limit, so it always carries the full 64-hex value.
