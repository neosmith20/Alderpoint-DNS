# Alderpoint DNS V2

The previous V2 implementation and its public planning document are frozen.

Alderpoint DNS **v1.1.1 remains the current public stable release**. Public V1 history, tags, release artifacts, and supported maintenance remain unchanged.

A clean V2 reboot is now under **private development**. Its implementation roadmap, architecture details, internal checkpoints, private build state, and release planning are intentionally not published here while development is active.

The old V2 code and tests are retained only as historical engineering evidence and as a source of selectively reusable behavior, tests, benchmarks, and lessons. They are not the architecture new V2 work continues by default.

No V2 release, release candidate, public package, tag, or public deployment should be inferred from activity in this repository unless an explicit V2 release is later announced.

For current public installation and operation instructions, use the v1.1.1 documentation in this repository and the latest stable GitHub Release.
